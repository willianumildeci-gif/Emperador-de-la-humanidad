# Sistema de ventas

Interfaz de gestión comercial hecha con Vite.

## Desarrollo

```sh
npm install
npm run dev
```

Genera el build de producción con `npm run build`.

## Datos

La aplicación almacena la información en `localStorage` del navegador y todavía no se conecta a una base de datos remota. El volcado SQL con datos personales se mantiene fuera de este repositorio público.
